# Predictive Demand Modeling & Market Potential Estimation (Pharma)

## 📋 Описание бизнес-кейса
Скрипт решает классическую задачу коммерческой аналитики в фармацевтическом секторе — планирование спроса (Demand Planning) и оценку рыночного потенциала при экспансии бренда на новые региональные рынки. 

Модель позволяет спрогнозировать будущие объемы продаж на основе планируемого охвата целевой аудитории (пациентов/врачей) и автоматически генерирует понятное для топ-менеджмента заключение.

## 🛠 Что делает данный скрипт:
1. **Моделирование зависимости**: Использует парную линейную регрессию (`statsmodels.formula.api`) для математического подтверждения связи между инвестициями в охват аудитории и финансовым результатом (выручкой).
2. **Предиктивный анализ**: На основе обученной модели рассчитывает точный прогноз продаж (в млн руб.) для нового региона с заданными параметрами емкости рынка.
3. **Автоматическая бизнес-интерпретация**: 
   - Самостоятельно оценивает коэффициент детерминации ($R^2$).
   - Переводит сухие статистические метрики на язык бизнеса (распределяет результаты по понятным «светофорным» зонам надежности: Высоконадежная / Удовлетворительная / Слабая модель).
   - Выводит готовые финальные рекомендации для коммерческого директора по планированию бюджетов и минимизации рисков дефектуры на складах.

## 💻 Стек технологий
Python (pandas, statsmodels).
